# 03 · 低成本创业方向：先建流水线，再谈点子

> 系列：行业研究 · 主题 03 ｜ 最后更新：2026-11 ｜ 文档性质：自有方法论 + 第三方市场数据转述

## 结论

低成本创业的关键不是「省钱」，也不是「想到一个好点子」，而是建立一条可持续的创意供给 + 快速验证流水线：创意有稳定来源、方向有筛选框架、验证成本压到 7 天以内。做不到这条流水线，方向池再长也只是一张清单。

## 关键发现

### 1. 创意来源的四条主渠道（自有方法）

1. **应用商店「高下载 + 低评分」**：需求存在，但现有方案没满足，痛点最诚实。
2. **社交平台的原生需求**：用户直接写出「希望有个 XX 软件就好了」，这是没被产品化的需求。
3. **行业报告与展会**：找大厂还没切进去的细分缝隙，而不是正面对抗。
4. **个人一线痛点**：自己愿意每天用、且能判断好坏的方向，验证成本最低。

### 2. 筛选框架：五个问题过一遍（自有方法）

市场规模与增长 → 竞争强度（大厂是否已切入）→ 技术与资源门槛是否在能力圈内 → 变现路径是否清晰 → 能否在 7 天内验证。任何一项答不上来，就先放着；「不能快速验证」是淘汰项，不是延后项。

### 3. 7 天低成本验证（自有方法）

不追求做出完整产品，只测最核心假设：有人愿意付钱吗、会重复用吗、愿意推荐吗。手段是落地页、手动服务、预售或社群，不是写代码。7 天结束要产出一个明确结论：继续、缩小范围，还是放弃。

### 4. 方向池只是候选（第三方 + 自有综合）

公开报告与个人观察给出的候选方向包括：老年服药提醒工具、宠物药品管理工具、极简家居收纳工具，以及 AI 健康监测挂件、模块化家庭服务机器人、基层医疗离线诊断、农业病虫害识别等。它们的共同特征是：需求明确、可以小规模验证、但渠道与合规才是真门槛。

### 5. 研究只能排除，不能证明（自有核心判断）

这些方向是「机会清单」而不是「结论」。研究能排除明显不行的方向，但不能证明哪个一定行。真正的决策依据是 7 天验证的结果，而不是报告里的市场规模。

## 对产品判断的启示

1. **先建流水线，再谈方向**：固定每周收集、打分、验证，把找方向变成流程而不是灵感。
2. **验证设计要写「证伪信号」**：不是「有多少人注册算成功」，而是「出现什么信号就停止」。
3. **优先验证成本最低的渠道**：先社群与落地页，后投流；顺序反了会把验证成本推高一个量级。
4. **硬件方向先看渠道与合规**：供应链、认证、售后是真门槛，没有渠道的工程师做硬件风险极高。
5. **用真实分布校正 TAM**：付费率、复购、获客成本这类「小数据」比 TAM 更能决定值不值得做。

## 不成立的条件

- 如果方向需要供应链、资质或长周期（如医疗器械、食品），7 天验证只能验证需求侧，验证不了交付可行性。
- 如果目标市场极小或极度垂直，应用商店下载/评分信号可能不足以支撑判断，需要换成访谈或社群验证。
- 如果验证样本只来自熟人社群，结论不可外推；熟人会为「支持你」而行动，不为需求而付费。
- 如果平台数据受刷量、运营活动或榜单机制污染，需求信号会有假阳性；此时应降级为线索而不是证据。
