# IndustryResearch · 行业研究

> 用研究支持判断，而不是用研究代替判断。

这是我在选方向、看赛道、判断一个产品值不值得投入时写的行业研究：8 个主题，每篇固定回答五个问题——结论是什么、关键发现里哪些是事实哪些是我的判断、对产品判断有什么启示、什么条件下这个结论不成立、来源与口径是什么。

本站页（结论层，适合两分钟扫完）：**[zhaolijian.github.io/research.html](https://zhaolijian.github.io/research.html)**　本仓库是长版（含来源编号、反例与口径检查表）。

## 阅读方式

1. 先读 [METHODOLOGY.md](METHODOLOGY.md)：我的四条研究方法、来源标注规则与数据口径检查清单。不认同这套口径，后面的结论都不用看。
2. 再按兴趣挑 `docs/01–08`。每篇结构固定：结论 / 关键发现 / 对产品判断的启示 / 不成立的条件 / 来源与口径。
3. 引用时请标注「作品集作者 · 行业研究」并附原文链接；引用其中的第三方数字时，请回到原报告核对——本仓库只做结论级转述。

## 标注与引用规则（摘要）

- 三色标注：**事实**（有可回溯来源）/ **我的判断**（个人推断，可被反驳）/ **待验证假设**（写清验证方式，验证前不进结论）。
- 第三方数据格式：**机构｜时间｜口径**。给不全时写「公开资料综合，待核对」，并说明缺的是哪一项。
- 只做结论级转述：不摘录报告段落、不复制图表与截图；竞品与厂商自述一律标「未独立验证」。
- 部分主题属于**委托研究 / AI 辅助研究**（如出海、OPC 方向研究），已在文中明确标注为「基于公开资料的综合整理」，不冒充一手调研。
- 所有涉及个人的调研对象均匿名化；本仓库不含客户实名与商业机密。
